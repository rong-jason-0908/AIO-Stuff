this generator is meant to take in a word from a predefined set as an input, and it outputs a 3d voxel model. The actual point is not a hardcoded model that's only trained on specific words, but a model that's trained on CLIP, using word embeddings that translate to voxel structure. Given more word-model pairs, this model may be able to generalize and achieve one shot learning (maybe in future work.)
